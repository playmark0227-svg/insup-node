# 新しい管理用スプレッドシートへの移行準備

**現状: Google 上の移行は未実行です。`Migrate.gs` の開始・継続関数は停止ガードで無効にしてあります。**

元ブックの画面でコメントが確認されています。`Sheet.copyTo` はタブの複製であり、コメントの本文・返信・作者・解決状態・元のセルへの紐づけまで同一に移ったことを、この方法では確認できません。ユーザーの「変更を加えない」という条件を満たす保全方法が決まるまで、停止ガードを外したり移行を実行したりしないでください。

既存の空の移行先ブックの ID は公開ソースに埋め込みません。移行先は、そのユーザー所有の新しいブックに紐づけた Apps Script の `getActiveSpreadsheet()` で決めます。元ブックに値・数式・書式・メタデータ等を書き込む処理はありません。

## 実装済みの部分と検証範囲

ローカルのモックで、ネイティブな全タブ複製、元の名前・順番・非表示状態の復元、名前付き範囲の移行、全タブ作成後の数式復元、値・数式・書式・結合・入力規則・条件付き書式・フィルタ等の照合をテストしています。入力値・書式・メモ等がある移行先には上書きしません。

複製時に生成される ID と、数式の再計算結果等は比較から除きます。元からある入力値・数式・書式・構造の定義を SHA-256 で照合し、元ブックの途中編集や移行先の手動変更を検出すると止まります。新しい数式エラーが生じた場合も止まります。タブ複製で引き継がれない保護範囲・メタデータ等がある場合も照合不一致で停止します。自動で元データを書き換えて解消する処理はありません。

コメント以外にも、画像・図形・フォーム連携・ピボット・スマートチップ・接続データ・スライサー・テーブルなど、同一性の確認を実装していない機能はコピー前に停止します。名前付き関数・マクロ・独自スクリプトは、Sheets API による今回の移行確認の対象外です。Google Drive の共有権限・変更履歴もタブ複製では移行できません。

API / Apps Script の実行時間制限に備え、処理は約 210 秒で区切って進捗を保存します。18 タブならおおむね 2〜4 回の実行を想定していますが、実際の時間は表の大きさと Google の応答によります。保存されるのは ID・進捗・件数・比較用ハッシュのみで、セル値や認証情報は出力・保存しません。途中中断の状態が不明な場合は二重コピーや自動上書きで回復せず停止します。

## 保全方法を解決した後の順番

1. 元ブックを読めるアカウントと、新しいブックの所有者を一致させます。
2. コメントを含め、変更しない条件と移行先の指定を満たす方法を確認します。Google のブック全体の「コピーを作成」でコメントを含める案は、別 ID の新ブックになるため、既存の空ブックへの移行とは異なります。
3. 移行先にはアプリの管理タブをまだ作りません。Google 権限の承認は所有者が行います。
4. 保全手順を反映・検証した移行処理を実行し、元と先を照合します。移行中は両方のブックへの手動編集を避けます。
5. 移行の確認後に、新しいブックだけを対象としてアプリ連携の `Code.gs` をセットアップします。元ブックを本番の書き込み先には設定しません。

```sh
node --test tests/migration.test.mjs
```
