# 紹介文の共通書式

この書式は、候補者を分かりやすく紹介するための一般的な文章ルールです。参考資料から共通する構成だけを取り入れ、個人の情報・実例・投稿へのリンクは含めていません。AIの学習用に原文を蓄積する仕組みではありません。

## 本文の構成

- **基本情報**：入力済みの情報を「項目：内容」で改行します。
- **営業経験・職務経歴**：会社・期間ごとに区切り、商材、対象、手法、主な業務、実績を分けます。記録のない会社・期間や雇用関係を補いません。
- **営業における強み**：本人が述べた強み、確認できる行動や工夫を具体的に記載します。能力や採用適性の推測へ広げません。
- **使用ツール**：使用経験の有無と未確認を区別します。PCを所持しているだけで、特定のツールが使えるとは扱いません。
- **面談可能日**：候補日・時間帯・調整中の条件をまとめます。未確定の候補を確定した予定に変えません。
- **総評**：経験領域、代表的な実績、具体的な工夫、稼働条件を基本の順序とし、入力済みの事実を自然な文章でつなぎます。通常は短い数文でまとめ、情報が少なければ短くします。

保存した口調・長さ・項目順・総評の有無を使用し、情報がない項目は省略します。空の見出しや「記載なし」を並べて長さを埋めません。総評は前の欄の箇条書きやラベルをそのまま繰り返す形にしません。

## 変えてはいけない意味

「約・最大・平均」「日次・時間あたり」「目標・実績」「本人申告」などの限定を保ちます。目標を実績に、最大を平均に、日次を月次に置き換えません。月と日、期間と日時を区別します。

原文に計算結果がない場合は、職歴の経験月数を合算したり、達成率・アポ率を計算したり、時給へ換算したりしません。不明な単位や比較対象は確認事項として分けます。

口語や誤字は意味が確実な範囲だけ整えます。人名・会社名・地名、数値、期間、否定、条件の範囲を推測で変えません。稼働開始可能日や希望を、実際に開始した実績として書きません。

## 本文と社内確認の分離

ヒアリング漏れ、提案先の相談、担当者の主観、内部の確認作業は、共有本文へ入れません。PCの所持状況や稼働の制約は確認済みの条件として扱い、背景の家庭・健康事情は共有しません。

未経験を可能性や期待の評価へ置き換えず、年齢や属性から人柄・能力を判断しません。即戦力や確実な活躍を断定する表現も、紹介文の標準ルールにはしません。

## 続けて使う方法

共通ガイドは文章作成のたびに使用されます。管理者が保存した有限の書式設定も次回以降に引き継がれるため、毎回参考文を貼り直す必要はありません。参考資料の原文を公開コードや共有設定へ保存せず、書き方だけを更新します。

端末AIの文章と、共通書式による下書きは分けて表示します。生成した文章は原文と照合して採用し、既存の文章を自動で上書きしません。このルールを入れただけで、生成結果のすべての事実が保証されるものではありません。
