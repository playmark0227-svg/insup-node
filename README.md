# INSUP NODE

管理者（PC）とプレイヤー（PC・スマートフォン）の成果・ランキング画面をGitHub Pagesで公開する静的Reactアプリです。

プレイヤー名簿はユーザー提供の7名です。成果・順位・月間目標は確認用サンプルです。Googleスプレッドシートへの保存と本番の本人認証は未接続です。画面での入力・編集は再読み込みでリセットされます。

## 開発と公開

Node.js 22.13以上で `npm ci`、`npm run dev` を実行します。`npm run build` は型チェックを行い、公開用ファイルを `docs/` に生成します。

GitHub Pagesは `main` ブランチの `/docs` を公開元に設定します。ソースの変更後は `npm run build` を実行し、生成された `docs/` とソースを一緒にコミット・pushしてください。

Viteのbaseは `/insup-node/` です。透過ロゴもこのサブパスから読込みます。元のSites版とその認証・接続用コードは、このリポジトリに含めていません。
